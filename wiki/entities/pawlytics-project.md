# Pawlytics Project

**Pawlytics** is an end-to-end stray animal analytics, incident tracking, and risk management web platform.

## Overview & Value Proposition
- **Citizen Empowerment**: Easy reporting of stray dog incidents, live safety mapping, safe route navigation, and educational safety guidelines.
- **Municipal Actionability**: AI-verified incident triage, real-time spatial hotspot detection, field action dispatching, ward risk scoring, and automated compliance auditing.

## Key System Components
- [[pawlytics-web-app]]: Main React + Vite web application codebase.
- [[citizen-portal]]: Public safety & reporting portal.
- [[authority-portal]]: Municipal command center & analytics dashboard.
- [[risk-engine]]: Spatial-temporal risk calculation engine & computer vision quality gate.
- [[supabase-backend-service]]: PostgreSQL database, authentication, and real-time backend layer.
